# css-base-1: style the café

Hands-on for Lecture 3. Everyone styles the same page, Kahvila Kaarna, a fictional café.

1. Open this folder in VS Code.
2. Open `index.html` in the browser (or with Live Server).
3. Edit only `style.css`. Follow the six steps written in it.

Don't change `index.html`. The point is to see how far CSS alone can take the same HTML.

`solution.css` is one possible answer. It's released after the lecture: to try it, change the `<link>` in `index.html` to point at `solution.css`.

Stuck? Open DevTools (right-click → Inspect, or F12) and check:

- Is `style.css` loading at all? Look in the Network tab.
- Is your rule listed in the Styles pane? If not, the selector doesn't match.
- Is it crossed out? Then another rule wins.
